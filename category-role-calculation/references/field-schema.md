# 品类角色字段说明

| 字段 | 中文名 | 说明 |
|---|---|---|
| `dimension` | 维度 | 例如 `门店_2025年03月`、`企业_春季`、`业态_冬季` |
| `period_type` | 期间类型 | `月度` 或 `季节` |
| `period` | 期间 | 月度如 `2503`，季节如 `春季` |
| `period_name` | 期间名称 | `2025年03月` 或 `春季` |
| `season_name` | 季节说明 | `春季`、`夏季`、`秋季`、`冬季` |
| `c_format_id` | 业态编码 | 来自门店信息表 |
| `c_format` | 业态范围 | 来自门店信息表 |
| `scope` | 计算口径 | `门店`、`企业`、`业态` |
| `scope_id` | 口径编码 | 门店编码、企业、或业态编码/名称 |
| `scope_name` | 口径名称 | 门店简称、企业、或业态名称 |
| `c_code` | 品类编码 | 3/4/5 级品类编码 |
| `c_name` | 品类名称 | 品类名称 |
| `c_skus` | 商品数 | 旧版兼容口径下，门店来自 `sale_lastyear_{period}` 正销售链路按 `c_gcode` 去重；业态/企业由门店结果取均值汇总 |
| `c_sale` | 销售额 | 当前口径品类销售额 |
| `c_pi` | 千人购买率 | `pi_count / pi_store_count * 1000` |
| `c_fi` | 千次购买率 | 门店综合得分使用归一化 FI：`c_fi_raw / 同品类门店均值`；业态/企业由门店结果汇总归一化 |
| `c_fi_raw` | FI 原始值 | FI 分子原始计数 |
| `c_pi_sku_ratio` | 单位 PI | `c_pi / c_skus` |
| `c_fi_sku_ratio` | 单位 FI | `c_fi / c_skus` |
| `c_sale_index` | 卖力指数 | 旧版兼容口径为 `销售占比 / SKU占比` |
| `c_sale_rate` | 销售占比 | 品类销售额 / 当前口径销售额 |
| `c_growth_store` | 超市增长率 | 使用 `sale_annual.csv` 与 `sale_annual_prev.csv` 计算，增长率超过 10 时封顶 |
| `c_id_count` | FI 分子 | 购买次数计数 |
| `c_id_count_store` | FI 分母 | 当前口径购买次数总数 |
| `c_dept_ccode` | 部门编码 | `10/30/40` 等内部编码 |
| `c_dept_name` | 部门 | `生鲜部`、`食品部`、`非食品部` |
| `c_ttno` | 企业编码 | 企业口径标识 |
| `c_score` | 综合得分 | 7 个指标排名分加权 |
| `c_score_sort` | 综合得分排名 | 当前口径内排名 |
| `c_score_avg` | 商品平均得分 | 默认等于综合得分；若后续有商品级模型可替换 |
| `c_score_avg_sort` | 商品平均得分排名 | 默认等于综合得分排名 |
| `c_class_role_id` | 品类角色 | `目标性品类`、`常规性品类`、`便利性品类` |
| `c_skus_rate_cp` | 商品数累计占比 | 按综合得分排序后的累计 SKU 占比 |
| `c_skus_rate` | 商品数占比 | 品类 SKU / 当前口径 SKU |
| `c_level` | 品类层级 | `3`、`4`、`5` |

## 季节映射

默认按月份映射：

- `3/4/5月` = 春季
- `6/7/8月` = 夏季
- `9/10/11月` = 秋季
- `12/1/2月` = 冬季

如果用户提供独立季节文件 `*_春季.csv`、`*_夏季.csv`、`*_秋季.csv`、`*_冬季.csv`，优先使用这些文件生成季节维度。
